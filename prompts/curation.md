# 策展：给每本上架的书写"你最舍不得的一句"和"这本书和你"

读 `library.py digest` 的输出，为 selection.json 里的每本书写一条记录，存成 `<work>/curation.json`：

```json
{
  "<bookId>": {
    "short": "书名的短写，必须是书名的一部分",
    "quote": "你最舍不得的一句",
    "about": "这本书和你：2–3 句",
    "tags": ["关键词1", "关键词2", "关键词3"],
    "related": ["<另一本上架书的 bookId>"]
  }
}
```

## 规则

**quote（最舍不得的一句）**
- 必须**逐字**摘自用户自己的划线或想法，不能改写、不能拼接、不能用书里用户没划过的句子。允许去掉首尾标点，或者只截取一条划线里完整的一句。
- 去掉空格和标点后至少 6 个字。更短的片段 check 会失败。
- 优先选：短（最好 40 字以内）、脱离上下文也能读懂、能代表用户在这本书里最在意的东西。用户自己写过想法的段落，优先考虑。

**about（这本书和你）**
- 写的是"用户和这本书的关系"，不是书的简介。用第二人称"你"。
- 只用数据里有的事实：什么时候读的、读了多久、读到多少、笔记最集中在哪一章、用户自己写下了什么话（用引号原样引用）。
- 不评价用户，不推断用户的心理或处境，不编造任何数据里没有的经历。
- 阿拉伯数字必须能在数据里对上（笔记条数、划线加想法、进度、阅读时长、笔记最多的章节各有几条、涉及的章节数、笔记跨越的天数和月数、年份个数等）。对不上 check 会失败。中文数字不自动核对，也不要靠它写数据里没有的数量。
- 2–3 句，口吻平静、具体，像一个认真读过你笔记的朋友。

**short**：书名的短写，比如去掉副标题。去掉空格和标点后必须是书名本身的一部分，不要另起一个名字。

**关键词（tags）**：最多 3 个，每个不超过 6 个字。必须是用户划线和想法里反复出现的概念，不是书的官方分类，也不是“成长”“人生”这类空泛词。

**related**：0–2 本，只能是本次上架的其他书（selection.json 里的 bookId，不能是这本书自己），选和这本书在用户划线里主题最接近的。

不要写 `author` 字段。作者只能来自微信读书数据。

## 追加新书

已经有 curation.json、这次只是再上架几本时，运行：

```bash
python3 scripts/library.py digest --data <data> --work <work> --only-new
```

只为这些新书写条目，合并进 curation.json。旧书的条目保留不动。

## 写完必须核对

运行 `python3 scripts/library.py check --data <data> --work <work>`，直到输出「全部通过」：
- 标 ✗ 的必须修改后重新核对。
- 数字在数据里找不到会失败：删掉或改写那句话。
- quote 去掉空格和标点后少于 6 个字会失败。
- short 不是书名的一部分会失败。
- 关键词超过 3 个，或某个关键词超过 6 个字会失败。
- related 不是本次上架的其他书会失败。
- 条目里如果有 author 字段会失败，删掉它。
